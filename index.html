About ELlipserWeb

Local photographic measurement and stain documentation in the browser.

What it does

ELlipserWeb calibrates photos, measures distances and angles, and fits ellipses to bloodstains so you can record impact angle (alpha) and travel direction (gamma). Images and measurements stay on this device.

Getting started

  1. File → New to name the case, or File → Open to load a saved .elp project.
  2. File → Import → Image to add photographs.
  3. Draw a Scale on a known length so later values are in real units.
  4. Use the left tools to measure. Ellipse → Assisted finds stain centers and fits half-ellipses.
  5. Open the chart icon on a Stains session in Structure for distributions and the stain table.
  6. File → Save writes the project. File → Export makes a CSV report, a printable PDF report, or a marked PNG of the current photo.

Tools and shortcuts

  • Scale, Measure, Circle, Ellipse, Polyline, Polygon, Text — click a tool, then draw on the photo.
  • Wheel zooms, right-drag pans, Delete removes the selection, F flips an ellipse, Ctrl+Z / Ctrl+Shift+Z undo and redo.
  • Per-stain arrows at centers set travel direction before or after a fit.

Capabilities

  • Calibrated length, width, alpha, and gamma for each stain.
  • Assisted detection with dark and light stain samples, detect/exclude regions, and manual marking.
  • Stain charts: impact-angle and width histograms, direction rose, width vs alpha, and a location map.
  • Project metadata, structure tree, and per-object styles.
